# Reproducibility-package separation

Source: bio-ontology-research-group/empty-quarter-mags at commit 9b15b60.
This repository is the independent empty-quarter-lifeonair package. Scientific input/output bytes are preserved; large-input checksums retain the source manifest values. Paths within the analysis bundle remain stable. Downloaded literature full texts are excluded from this new distribution; bibliographic notes and retrieval manifests remain. Historical review receipts refer to their original locations.

The manuscript editing checkout is `~/Documents/papers/empty-quarter-lifeonair/`; the GitHub package checkout is `~/Public/software/empty-quarter-lifeonair/`. The Overleaf and GitHub repositories have separate histories. Original repositories/checkouts are retained, so reverting the split requires no data restoration.

The package verifies frozen results and builds the paper. Upstream analysis on raw reads remains subject to the documented data-access, database and environment prerequisites. Publication of this package does not certify unresolved raw-input provenance or create a data-archive DOI.

Bulk-input storage: per Robert's instruction, large files remain on IBEX. GitHub contains compact evidence, source code and checksum/location manifests. The briefly created bulk-data releases were removed; no bulk input was committed to Git history. Fetching these inputs requires authorised institutional access.
