Here are the actionable findings regarding potential leakage, implementation edge-cases, and modeling behavior:

### 1. Leakage risk in taxonomic fold splitting (`analysis_plan.txt`)
**Issue:** The plan states: *"five deterministic grouped folds by genus (unassigned genera are kept together within their family/order)."*
If the downstream analysis script implements this by simply using the `genus` column for `GroupKFold`, all unassigned MAGs (e.g., `""` or `NA`) across the entire dataset will be pooled into a single, massive "unassigned" fold.
**Impact:** This violates phylogenetic separation. Unassigned MAGs in the test fold could belong to the exact same families or orders as named genera in the training folds, leaking phylogenetic traits.
**Action:** The analysis script must construct composite pseudo-labels for unassigned taxa (e.g., `unassigned_<FamilyName>`) prior to fold splitting to maintain independent phylogenetic blocks.

### 2. H2 Symport inclusion in hydrogenase reporting (`gapseq_pilot_simulate.py`)
**Issue:** At line 23, the script identifies H2-involving reactions using `len({base(z) for z in x.metabolites}) > 1`. This safely excludes pure H2 diffusion (`H2_e <=> H2_c` has length 1), but it will falsely capture H2 symports (e.g., a proton symport `H2_e + H+_e <=> H2_c + H+_c` evaluates to length 2).
**Impact:** Benign for simulation. Because this pilot script only logs these reactions to the `rx` audit trail (unlike the parent `metabolic_simulate.py` which actively knocks them out), it will not break the ATP/growth solves. However, it may slightly inflate the reported native hydrogenase counts in the audit logs.
**Action:** If strict metabolic-only hydrogenases are desired for the audit, you may need to explicitly filter out known transport/symport reaction IDs.

### 3. Structural behavior of Validation B Baseline (`analysis_plan.txt`)
**Observation:** Validation B ("grouped site folds") predicts test-site means using models trained on training-site means. Because the features are purely MAG-level (taxonomy, genome length), the features for a MAG are identical in the train and test splits.
**Impact:** The baseline model uses the `order` and `marker group` categorical features to essentially fit a taxonomic random effect that memorizes the training-site means. The fixed Ridge penalty ($\alpha=10$) is critical here—it prevents perfect memorization and forces the model to rely on broader taxonomic averages.
**Assessment:** This is not a bug and matches the stated goal (*"measures geographic repeatability"*). Adding metabolic traits will correctly test whether they explain a MAG's test-site variance better than its taxonomic baseline. No action is required; the mathematical structure is sound for the ecological intent.
